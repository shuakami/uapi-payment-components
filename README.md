# UAPI Payment Components

React components for compact checkout flows:

- `ProductCard`
- `PaymentModal`
- `PaymentSuccessModal`

```bash
npm install uapi-payment-components
```

```tsx
import {
  ProductCard,
  PaymentModal,
  PaymentSuccessModal,
} from "uapi-payment-components";
import "uapi-payment-components/styles/payment-modal.css";
```

The components are styled with Tailwind utility classes.
